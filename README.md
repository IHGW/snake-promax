# 🐍 贪吃蛇 Pro Max

> 用 C 语言 + ACLLib 写的贪吃蛇，从 3 行代码到 1200+ 行，一步步长出来的项目。

## ✨ 功能

- **三种模式**
  - 单人游戏
  - 双人模式（WASD vs 方向键/小键盘）
  - AI 对战（AI 用「4 方向评分 + 曼哈顿距离」自动追食物）
- **难度选择**（速度 + 障碍加成：难度越高，加速越多、障碍越多）
- **多种道具**（可多选组合）
  - 障碍物：撞墙扣命
  - 传送门：进一个门从另一个门出来
  - 神秘道具：加命 / 减命 / 加速 / 减速（效果随机，保持神秘）
- **系统**
  - 最高分（本地文件保存）
  - 暂停（ESC）
  - 回菜单（4）
  - 加速系统（每吃 3 个食物快一档）
  - 每吃 3 个食物加一条命
  - 扣命闪烁
  - 音乐开关（L）+ 音量图标
  - 菜单/游戏双 BGM

## 🎮 操作

| 按键 | 功能 |
| --- | --- |
| `5` / `6` / `7` | 单人 / 双人 / AI 对战 |
| `C` / `V` / `B` / `N` | 障碍物 / 传送门 / 神秘道具 / 全部关闭 |
| `1` / `2` / `3` | 难度 |
| `R` | 开始 / 重新开始 |
| `ESC` | 暂停 |
| `4` | 回菜单 |
| `L` | 音乐开关 |
| `WASD` | 玩家 1 |
| `方向键` / `小键盘 8 2 4 6` | 玩家 2 |

## 🛠 编译

### Dev-C++

1. 打开 `贪吃蛇！启动！！！.dev`
2. 链接参数（项目属性 → 参数 → 链接器）：

```text
-lwinmm -lmsimg32 -lgdi32 -luser32 -lkernel32 -lole32 -loleaut32 -luuid
```

3. F11 编译运行

### gcc 命令行

```bash
gcc main.c keyboard.c timer.c else.c acllib.c -o snake.exe ^
    -lwinmm -lmsimg32 -lgdi32 -luser32 -lkernel32 -lole32 -loleaut32 -luuid
```

## 📁 文件结构

```text
main.c       全局变量 + Setup
main.h       声明、宏（GRID_COLS、MOVE、boundary 等）
keyboard.c   按键（模式/道具/难度/方向/暂停/返回）
timer.c      定时器主循环（移动/生成/绘制）
else.c       核心函数（重置/碰撞/道具/传送/AI）
acllib.c/h   ACLLib 图形库
bgm.wav      菜单 BGM
bgm_game.wav 游戏 BGM
```

## 📌 说明

- 网格系统：所有坐标都是 20 的倍数（`MOVE=20`），蛇、食物、道具对齐网格
- 判定：蛇头方块 ±10，撞墙/撞蛇用精确坐标判断
- `gen_ins(x, y, sign)`：通用坐标检查（食物、三条蛇、其他道具），`sign` 是"当前正在生成的道具类型"（跳过自己）
